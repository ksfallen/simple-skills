## 模版使用规则

1. 章节标题与顺序**不可变更**（测试/运维按固定章节取信息）；无内容的章节写"无"，不删章节
2. 文档头部固定包含提测人、提测日期和 `[创建itop工单]` 链接；交付模式默认「标准协作」，明确单人交付时写「单人交付」
3. 功能描述用编号列表，每条以加粗功能点名开头；有产品地址时地址链接放描述之前
4. 测试用例编号从 TC-01 连续递增；场景写操作、预期写可验证结果；复杂用例外链知识库用例文件
5. 部署服务表的服务行数 = 实际需要部署的模块数（多模块单仓库时按部署单元拆行）；服务类型取 后端/前端/小程序/定时任务
6. DDL 必须可直接执行；索引与字段分开两条语句；执行顺序明确写「优先执行」或「后执行」
7. 数据库变更若目标环境可能已执行过，在说明中补一句"若已执行可跳过"
8. 配置按 Apollo配置 / 配置文件 / 其他配置 归类；数据初始化类配置归入"其他配置"并注明库表与执行 SQL
