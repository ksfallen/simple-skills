# 代码审查清单

按维度逐项过一遍改动。**只报能在 diff/源码里指出证据的问题**；没有证据的写"待确认"。

## 1. 变更完整性与意图

- 提交信息与实际改动是否一致；是否夹带无关改动、格式化噪音、临时文件
- 是否漏提交（新增文件、配置、DDL、依赖声明、前端打包产物）
- 是否残留 `TODO`/`FIXME`/调试输出/注释掉的代码/`<<<<<<<` 冲突标记
- 生成代码、二进制、锁文件是否应入库；体积是否异常

## 2. 正确性与边界

- 空值：`null`、空集合、空字符串、Optional 误用；包装类型拆箱 NPE
- 边界：0、负数、最大值、超长字符串、时区/夏令时、跨天/月末
- 精度：金额用 `double/float`、除法取整、币种/单位换算
- 相等性：`==` 比较字符串/包装类型、`equals` 未处理 null、枚举序列化
- 循环：边界 off-by-one、`break/continue` 遗漏、集合遍历中修改
- 返回值：分支漏 return、异常路径返回不完整对象、默认值掩盖错误

## 3. 并发、事务与幂等

- 共享可变状态：单例成员变量、静态集合、非线程安全类（`SimpleDateFormat`、`HashMap`）
- 锁：锁粒度、锁顺序（死锁）、`synchronized` 锁错对象、分布式锁续期/释放
- 事务：`@Transactional` 自调用失效、异常类型未触发回滚、事务内做 RPC/长耗时
- 幂等：重复请求/重复消费/重试是否产生重复扣款、重复开卡、重复记账
- 一致性：缓存与 DB 更新顺序、并发更新丢失、乐观锁版本号

## 4. 数据库与 SQL

- DDL：字段类型/长度/默认值、`NOT NULL` 加列、索引缺失、大表变更锁表、可回滚性
- SQL：全表扫描、`LIKE '%x'`、隐式类型转换、`OR` 破坏索引、深分页
- MyBatis：`${}` 注入、`#{}` 与 `${}` 混用、动态 SQL 漏 `where`、`resultMap` 字段错位
- 批量：循环单条写库（N+1）、批量大小无上限、事务过长
- 数据迁移：存量数据兼容、灰度期间新旧字段并存、回滚脚本

## 5. 接口与兼容性

- RPC/HTTP 契约：字段删除/重命名/必填变更、枚举新增值、返回结构变化
- 序列化：日期格式、`null` 字段是否输出、大小写/下划线策略
- 老客户端：新增必填参数、默认值缺失、版本协商
- 内部方法：公共方法签名/语义变更，Grep 全部调用方确认
- 消息/缓存：topic、key、value 结构变更是否兼容在线消费者/旧缓存

## 6. 配置与开关

- 新增配置项：默认值是否合理、缺失时行为（启动失败还是降级）、各环境是否齐全
- 硬编码：地址、端口、AppId、密钥、超时、批次大小
- 开关/灰度：关闭时是否回到旧逻辑、开关读取时机（启动 vs 每次请求）
- 多环境差异：SIT/生产端点、库名、topic、证书

## 7. 安全与合规

- 密钥/口令/私钥/Token 是否硬编码或入库；日志是否打印敏感字段（手机号、身份证、卡号、金额明细）
- 越权：用户身份是否校验、资源归属是否校验、管理接口是否鉴权
- 注入：SQL、命令、模板、反序列化（`readObject`、Fastjson autoType）
- 上传/下载：路径穿越、文件类型校验、大小限制
- 外部输入：签名/验签、重放、限流

## 8. 异常、重试与资源

- 吞异常：`catch (Exception e) {}`、只打日志不处理、返回 `null` 掩盖失败
- 异常类型：把业务异常包成系统异常（或反之），影响上游重试/告警
- 重试：无上限、无退避、非幂等操作重试
- 超时：RPC/HTTP/DB 未设超时；线程池队列无界
- 资源：流/连接/游标未关闭，`try-with-resources` 缺失，线程池未复用

## 9. 性能与容量

- 循环内 RPC/查库/发消息；批量接口逐条调用
- 大对象/大集合进内存；无分页查询；导出无上限
- 缓存：击穿/雪崩、key 无过期、缓存大 value
- 索引与执行计划：新增查询是否有对应索引（必要时 `EXPLAIN`）

## 10. 可观测性与回滚

- 日志：关键入参/出参、traceId、错误堆栈；级别是否合理（不要用 ERROR 打业务提示）
- 监控：核心链路有无埋点/告警；失败是否可发现
- 回滚：服务回滚是否足够；DDL/数据变更是否可回退；开关能否快速关闭新逻辑
- 发布顺序：跨服务/跨仓库改动是否需要同批发布，避免口径不一致窗口

## 语言/框架补充

**Java / Spring**

- Bean 注入：循环依赖、`@Autowired` 字段注入、`@Qualifier` 缺失
- 事务传播：`REQUIRES_NEW` 用法、事务内异步、`@Async` 丢上下文
- 配置绑定：`@Value` 默认值、`@ConfigurationProperties` 校验
- 线程池：`Executors` 默认工厂、拒绝策略、上下文透传

**前端 / Node**

- 请求：错误分支未处理、loading/重复提交、竞态（旧响应覆盖新响应）
- 渲染：`v-html`/`dangerouslySetInnerHTML` XSS、key 缺失、内存泄漏（定时器/监听未清理）
- 依赖：lock 文件变更、重大版本升级、打包体积

**脚本（Python/Shell/PowerShell）**

- 路径：硬编码绝对路径、Windows/Linux 分隔符、含空格/中文路径未加引号
- 幂等：重复执行是否安全、失败是否留下半成品
- 密钥：配置文件是否被 `.gitignore` 排除、模板是否脱敏
- 错误处理：`set -e`、子命令失败是否检查、清理逻辑（`finally`/`trap`）
